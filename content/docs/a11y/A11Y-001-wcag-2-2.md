# A11Y-001 — WCAG 2.2

## Summary
WCAG 2.2 defines testable criteria; use Level AA as the project baseline where applicable.

## MUST
- A11Y-001.M1: Assess applicable WCAG 2.2 A and AA criteria, including 2.2 additions.

## SHOULD
- A11Y-001.S1: Include focus not obscured, dragging movements and target size in applicable audits.

## AVOID
- A11Y-001.A1: Do not claim conformance from an automated scan alone.

## DECIDE
| Situation | Decision |
|---|---|
| Native element fits | Use native semantics |
| Custom widget needed | Follow pattern and test |
| Scan passes | Continue manual review |

## STATES
- Default
- Keyboard
- Screen reader
- Zoom/reflow
- Error
- High contrast/reduced motion

## EXAMPLE
Drag-to-reorder must have a non-drag single-pointer alternative under SC 2.5.7.

## FAILURE MODES
- A polished screen can still fail the task; validate against the defined user outcome.
- A heuristic is not a WCAG success criterion unless explicitly identified as one.
- If project context conflicts with this guidance, record the conflict and obtain an explicit decision.

- [ ] A/AA checked?
- [ ] Manual keyboard/AT included?
