# Admin Panel Specification

Pages: Overview, Docs, Packs, Routing, Releases, API Keys, Usage, Compliance, Gaps and Settings.

Docs: filter by domain/tag/status/priority; Markdown editor and preview; front matter; token count; link/source checks; revision diff. Block publish on invalid required sections or IDs.

Packs: ordered IDs, resolved titles, token totals, missing/deprecated warnings; enforce 6,000-token proposal budget including core. Routing: keyword rules, collision checks and test descriptions. Releases: change summary, semver, eval scores, staging, publish and rollback. Keys: create/revoke/pin/rate limit; plaintext shown once. Usage/compliance: calls, latency, errors, top docs, skipped stages, unfetched citations and unknown IDs.

Roles: admin all; editor docs/packs/drafts; publisher release/rollback; viewer read-only dashboards.
