# Content Governance

Statuses: draft (incomplete); reviewed (human source/content review complete but unreleased); published (included in immutable release); deprecated (excluded from active retrieval, history retained).

Every topic requires valid ID/domain/file match, specific rules, decision table, states, example, checks, credible sources, valid related IDs and no boilerplate duplication. Numeric thresholds must be standards-backed or explicitly labeled as practical heuristics.

Workflow: draft → structural/link/source/repetition checks → human review → stage-pack/route impact review → regression → release candidate → staging test → publish immutable snapshot.

WCAG and applicable law/platform requirements outrank internal convenience. Project design systems can override aesthetic defaults, not accessibility or safety. Record conflicts.
