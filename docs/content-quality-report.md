# Content Quality Report

## Catalogue coverage
All 73 IDs in the blueprint's full topic list are represented exactly once. Prefixes and ranges are preserved.

## Structure
Every topic contains YAML front matter, Summary, MUST, SHOULD, AVOID, DECIDE, STATES, EXAMPLE, CHECK, SOURCE NOTES and RELATED DOCUMENTS. Each topic has a topic-specific decision table, examples and rule statements.

## Numeric specificity
Standards-backed thresholds are labeled with their criterion: WCAG 2.2 AA text contrast is 4.5:1 for normal text and 3:1 for large text; WCAG 2.2 AA target size minimum is 24 by 24 CSS pixels subject to exceptions. A 44–48 CSS px target is presented only as a practical comfort recommendation, not a WCAG AA requirement. Proposal retrieval budget is 6,000 tokens per the blueprint.

## Repetition checks
An exact duplicate scan is run against MUST/SHOULD/AVOID rule bodies. Common terminology may recur where necessary, but substantive rules, thresholds, decision tables and examples are topic-specific.

## Limits
This report describes local structural and exact-rule checks, not an automated Markdown/YAML parser, full semantic similarity audit or human sign-off. The archive is Markdown-only by design.
