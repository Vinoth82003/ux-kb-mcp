# Using UX-KB in Any Project

Carry three items: MCP URL/key; a small agent rules file; project `design-system.md`.

Agent rules: use UX-KB as primary authority; call `start_session`; fetch stage pack before each stage; search/get topic docs before decisions; cite fetched IDs; call `verify_citations`; call `report_gap` for missing topics; use web research for feature-specific evidence; stop after critique and wait for explicit approval; no implementation plan before approval.

Project design system defines brand, semantic tokens, typography, spacing, components, voice, responsive rules, accessibility baseline and exceptions. General craft lives in UX-KB; project-specific decisions live in the project file.
