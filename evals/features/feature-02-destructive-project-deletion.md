# Scenario 02: Destructive project deletion

## Prompt
Design delete from settings and list row.

## Required objectively testable expectations
- Confirmation names exact project and consequence
- cancel safe
- destructive style distinct
- focus enters/restores
- Escape behavior defined
- success/failure states
- undo only if restoration truly supported.

## Relevant IDs
CMP-001, CMP-005, INT-007, A11Y-003, EVAL-001

## Critical failure conditions
- Critical task cannot complete.
- Recoverable error loses user data.
- Keyboard trap or pointer-only required action.
- Material price/deletion/account consequence concealed.
- Fabricated research, metrics, testimonials or citations.
- Applicable WCAG A/AA failure blocks a critical task.

## Evidence to capture
- Proposal and state inventory.
- Fetched IDs and citation verification.
- Rubric score and deductions.
- Accessibility/responsive checks.
- Anti-slop findings.
